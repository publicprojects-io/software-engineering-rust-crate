# Changelog

All notable changes to this project are documented here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic
Versioning.

## [Unreleased]

## [1.1.1] - 2026-11-19

### Added

- A 100% coverage gate powered by `cargo-llvm-cov`.
- User guides, runnable examples, security policy, stability policy, roadmap,
  API index, architecture notes, and dependency documentation.
- docs.rs metadata and package-status badges.
- Property, mutation, fuzz, benchmark, CodeQL, and supply-chain verification.
- Reproducible release packaging with an SBOM, checksums, and provenance
  attestations.

### Changed

- The default Rust toolchain now matches the declared Rust 1.98 MSRV.

## [1.1.0] - 2026-11-17

### Added

- Coverage and benchmark command wrappers.
- Contributor and AI-agent guidance.

### Changed

- Financial modules demonstrate direct `rusty-money` usage rather than thin
  wrapper APIs.

## [1.0.0] - 2026-11-17

### Added

- Initial stable release with 29 specification-driven metrics modules.
